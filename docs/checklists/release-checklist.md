# Checklist — Release (Electron / APP)

- [ ] Version bump conforme o acordo do repositório
- [ ] Tag `vX.Y.Z` alinhada ao `package.json`
- [ ] Changelog / notas de release (se o projeto usar)
- [ ] Smoke: app, liturgia e projeção em pelo menos 2 monitores
- [ ] Artefato do electron-builder testado no SO alvo
- [ ] `docs/DEVELOPER.md` / `docs/context/` atualizados se a arquitetura mudou
